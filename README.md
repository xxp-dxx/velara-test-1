# Velara

Build repository for the original Velara 0.1.0-alpha source bundle.

The repository reconstructs the source bundle from `source-parts/` and uses GitHub Actions to build:

- Minecraft 1.21.11 + Fabric
- Minecraft 1.21.11 + Forge
- Minecraft 26.3 + Fabric
- Minecraft 26.3 + Forge

The build artifacts are attached to the workflow run under **Artifacts**.

This repository is intentionally separate from any later Velara test version.
